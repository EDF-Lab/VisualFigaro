Pour installer un .deb : sudo dpkg -i nom_archive.deb
Puis pour réparer les dépendances : sudo apt-get –f install

Pour figp, il n'y a pas de dépendances, il suffit de recopier figp dans /bin


Pour installer lib32stdc++6 si nécessaire : sudo apt -get install lib32stdc++6 lib32z1 lib32z1-dev
